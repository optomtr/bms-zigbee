# BMS Zigbee — журнал

## 2026-10-23 · дополнение 2.14.2-bms.3 · старые группы от хаба Tuya

- Первый живой запуск: SLZB-06M (EmberZNet 8.0.2) найден сам, канал 11 по замеру, сеть на 13 dBm,
  подключено 18 контроллеров света Tuya TS0502B.
- Найдено на живой сети: у устройств, перенесённых с хаба Tuya, остаются старые группы, и Z2M не может
  добавить их в свою группу (команда таймаутит). Слой Tuya теперь сам очищает таблицу групп после первого
  знакомства, если по базе Z2M устройство ещё ни в одной группе. Настроенные группы, пульты и кнопки
  сцен не трогаются. Тесты слоя 30, библиотеки 18.
- Не проверено на живых устройствах: очистку на новых лампах увидим при следующем подключении.

## 2026-10-23 · дополнение 2.14.2-bms.2 · координатор находится сам

- Адрес SLZB-06M вписывать не нужно (`serial.port: auto`): дополнение перебирает адреса локальной сети
  (сети берёт у Supervisor), находит координатор по порту 6638 и запоминает его серийный номер (EUI64).
  Сменился IP — находит тот же координатор, чужой не берёт.
- Координатора ещё нет — дополнение ждёт и проверяет сеть раз в 30 с; подключили — стартует само.
- Прошивка координатора старее EmberZNet 7.4 — Z2M не запускается, в журнале по-русски написано,
  где обновить; после обновления запуск идёт сам.
- Ядро 10.10.0-bms.2: новая утилита `coordinatorCli.js` (probe/discover), 1891 тест.
- Проверено в Docker на имитации координатора и на настоящем ядре: все сценарии поиска и ожидания.
  Не проверено: живой SLZB-06M, установка в Home Assistant.

## 2026-10-23 · дополнение 2.14.2-bms.1 · первая публикация

Свой Zigbee для устройств Tuya: Zigbee2MQTT 2.14.2 + наше ядро zigbee-herdsman 10.10.0-bms.1 +
слой Tuya, координатор SMLIGHT SLZB-06M. Адрес для Home Assistant: https://github.com/optomtr/bms-zigbee

**Что внутри**
- Ядро (`core/patches`): повтор доставки команд, 19 dBm на 60 с при переподключении устройства,
  перестройка маршрутов после его возврата, замер эфира для выбора канала.
- Слой Tuya (`tuya/layer`): ответы на служебные запросы Tuya, особый запрос при подключении,
  сырые точки данных неизвестных моделей, описание моделей через `bms-models.yaml`.
- Дополнение (`addon/bms_zigbee`): при новой установке мощность 13 dBm, проверка «живо ли»,
  самый тихий канал при первом запуске.
- Замерщик стенда (`harness`) и библиотека точек данных (`tuya/library`).

**Проверено:** тесты ядра 1817, слоя 25, библиотеки 18, замерщика 54; сборка и запуск
дополнения в Docker на имитации координатора.

**Не проверено:** настоящий SLZB-06M, живые устройства Tuya, установка в Home Assistant.

**Дальше:** этап 0 — стенд и первый замер против хаба Tuya.
