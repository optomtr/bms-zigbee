# BMS Zigbee — правила для разработки

Свой Zigbee для устройств Tuya: Zigbee2MQTT + наша правка ядра + наш слой Tuya,
координатор SMLIGHT SLZB-06M.

## Кто где пишет

| Папка | Что | Пишет |
|---|---|---|
| `harness/` | Замерщик: сценарии стенда, сравнение хаба Tuya и нашей стороны | только задача «замерщик» |
| `core/` | Наша копия zigbee-herdsman: закреплённая версия + наши патчи + сборка tgz | только задача «ядро» |
| `addon/` | Дополнение Home Assistant «BMS Zigbee» | только задача «дополнение» |
| `tuya/` | Слой Tuya и библиотека моделей (точки данных) | только задача «библиотека» |

Чужие папки — только читать. Временное — в `<своя папка>/.work/` (в .gitignore).

## Версии

Единственный источник — `versions.json`. Версию меняем там, а не в коде.

## Правила

- Ничего не коммитить и не пушить: коммитит диспетчер после проверки.
- Репозиторий BMS Integration (GitHub `optomtr/bmsintegration`, локальная копия) — только читать:
  не переключать ветки, не трогать рабочее дерево.
- Комментарии в коде — по-русски и про «почему».
- Каждое «работает» подтверждать запуском: команда и её вывод в отчёте.
- В README своей папки (по-русски): что это, как запустить, что проверено, что нет.
