# Исходные макеты пользователя

`desktop.html` и `iphone.html` — неизменённые файлы из Downloads, переданные для переноса 1:1. CSS, шрифтовые декларации, исходные переключатели и анимации сравниваются с ними. Эти файлы не входят в Docker-образ.

Рабочие копии находятся в `bms_zigbee/rootfs/opt/bms-ui/`. В них добавлены только адаптер данных, контекстный доступ к управлению устройством и недостающие разделы BMS внутри MQTT/Брокера. Встроенные React/ReactDOM имеют MIT-лицензию; её текст сохраняется в образе как `REACT-LICENSE.txt`.
