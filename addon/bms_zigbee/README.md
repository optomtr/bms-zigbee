# BMS Zigbee

Zigbee2MQTT с нашим Zigbee-ядром и нашим слоем поддержки устройств Tuya.
Работает с сетевым координатором SMLIGHT SLZB-06M. Основано на официальном
дополнении [zigbee2mqtt/hassio-zigbee2mqtt](https://github.com/zigbee2mqtt/hassio-zigbee2mqtt).

Ничего вписывать не нужно: воткните координатор в ту же сеть, что и Home Assistant, — дополнение само его найдёт
(и подождёт, если он ещё не подключён). Остальное (мощность, самый тихий канал, проверка «живо ли»)
оно тоже настраивает само, как шлюз Tuya.

Подробности — на вкладке «Документация».
